### Definitions

**Draft** — Documentation is being prepared prior to submission.\
**Filed** — A DMCA notice has been submitted to the recipient and is awaiting\
**Notice** — A DMCA notice was sent to the website or its designated contact, but no response or action has been received.\
**Acknowledged** — The recipient has confirmed receipt of the notice\
**Removal** — The website removed the unauthorized QoF mirror following the DMCA request.\
**Escalated** — The matter has been referred to an upstream service provider, hosting provider, domain registrar, search engine, or other intermediary following the absence of a satisfactory response.\
**Rejected** — The recipient declined to comply with the request.\
**Counter Notice** — A valid DMCA counter-notification has been received.\
**Restored** — Access to the reported material has been reinstated following a counter-notification or other legal process.\
**Closed** — The enforcement matter has concluded. No further action is anticipated.

### Escalation Types

**Search Engine Removal** — Removal request submitted to search engine providers to de-index infringing URLs.\
**Hosting Provider Notice** — Notice submitted to the hosting provider responsible for serving the infringing content.\
**Domain Registrar Notice** — Notice submitted to the domain registrar requesting action in accordance with its abuse or copyright policies.\
**CDN / Reverse Proxy Notice** — Notice submitted to CDN or reverse proxy providers facilitating access to the infringing content.\
**Platform Report** — Copyright report submitted through an online platform's official reporting process.
